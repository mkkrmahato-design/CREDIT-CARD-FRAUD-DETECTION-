# Credit Card Fraud Detection Using Anomaly Detection Techniques

## Tools Used
- Python
- NumPy
- Pandas
- SciPy
- Scikit-learn

## Techniques Used
- Z-Score
- IQR Method
- Isolation Forest
- Local Outlier Factor (LOF)

## Project Objective
To detect fraudulent credit card transactions using anomaly detection techniques and evaluate their performance using precision and recall metrics.
